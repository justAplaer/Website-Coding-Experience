# Website-Coding-Experience
The following folder provides an overview on the two strongest websites I built during my foundation as a programmer at 12-14 years old. Through these websites I have sharpened my python, Html, and style.css skills

Diary
  A personal diary web app built with Flask, HTML/CSS, and SQLite. It supports account registration and login, creating and browsing diary entries, and includes an experimental voice-to-text feature for dictating posts. An early independent project where I explored databases, user flows, forms, and speech recognition.

  
Energy Efficiency Calculator
    
    An interactive Flask web app that estimates a home’s energy efficiency from its size, lighting, and number of electrical devices. It guides users through a visual multi-step calculator, gives feedback based on the result, and includes a form for requesting an eco-friendly home setup. An early independent project combining Python logic, routing, forms, and frontend design.
